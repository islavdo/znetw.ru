БЫСТРЫЙ СТАРТ

Рассылка за 7 шагов

Если Mass Mailer уже установлен, этого сценария достаточно для обычной работы.

  1. 1

    Создайте письмо-шаблон

    В Outlook Classic создайте новое письмо или откройте несохранённый/неотправленный черновик. Заполните тему, текст, подпись, CC/BCC и выберите нужный From.

  2. 2

    Запустите MassMail_Open

    Макрос возьмёт активное открытое письмо; если отдельное окно письма не активно — попробует использовать один выбранный элемент в Outlook.

  3. 3

    Проверьте шаблон

    Убедитесь, что в блоке Email Template корректны Subject, CC, BCC, вложения и превью, а справа отображается правильный From.

  4. 4

    Добавьте получателей

    Вставьте адреса вручную, выберите Preset или используйте Import. Дождитесь корректного счётчика Valid / Invalid / Duplicates.

  5. 5

    Выберите режим

    Для первой проверки и крупных пакетов используйте Create drafts. Для прямой отправки — Send now.

  6. 6

    Нажмите Create Mailing

    Проверьте сводку подтверждения. Mass Mailer создаст по одному отдельному письму на каждый валидный уникальный TO.

  7. 7

    Если создали черновики — проверьте и отправьте

    Откройте несколько подготовленных писем, проверьте From/TO/CC/BCC/вложения, затем нажмите Send Prepared Drafts.

ПЕРЕД УСТАНОВКОЙ

Требования и совместимость

Outlook Classic for Windows

Макрос использует классическую Outlook Object Model и VBA. Новый Outlook для Windows для этого сценария не подходит.

VBA Project

Должен быть доступен редактор VBA по Alt + F11. В корпоративной среде доступ может регулироваться политиками IT.

Разрешённые макросы

Используйте настройки безопасности вашей организации. Не рекомендуется глобально включать все макросы только ради установки.

Почтовый аккаунт Outlook

Письма физически отправляет Outlook через настроенный профиль. Лимиты Exchange/SMTP и серверный throttling продолжают действовать.

Перед массовой рассылкой: обязательно выполните тест на 1–2 своих адресах и проверьте фактический From, TO, CC/BCC, тело письма и вложения.

ШАБЛОН

Как Mass Mailer получает письмо

Источник шаблона

При запуске MassMail_Open используется приоритет:

  1. Текущее письмо в активном отдельном окне Outlook.
  2. Если его нет — ровно один выбранный элемент в основном окне Outlook.

Письмо должно быть неотправленным. Уже отправленное письмо нельзя использовать как активный шаблон.

Что сохраняется в шаблоне

  • Subject и тело письма.
  • Форматирование/подпись, сохранённые Outlook в OFT.
  • CC и BCC.
  • Вложения.
  • Контекст отправителя / From.
Ключевой принцип: адреса из поля TO исходного письма не используются как общий список рассылки. Для каждого созданного письма TO очищается и заменяется ровно одним адресом из блока Recipients. CC и BCC остаются из шаблона.

Кнопки Email Template

Edit

Открывает рабочую копию шаблона в Outlook. Внесите изменения в тему, текст, From и т.д., после чего нажмите Refresh в Mass Mailer.

Attach

Добавляет выбранные файлы непосредственно в сохранённый snapshot шаблона.

Refresh

Считывает заново текущее открытое письмо: обновляет snapshot, превью и контекст отправителя.

?

Открывает текущую страницу инструкции: https://znetw.ru/massmailerinfo.

FROM И ПАПКИ

Отправитель и маршрутизация

From

Отправитель не выбирается вручную в интерфейсе Mass Mailer. Он наследуется из исходного письма-шаблона.

Если справа отображается (Outlook default account), Outlook не зафиксировал отдельный SendUsingAccount и будет использовать контекст/default account профиля.

Нужно изменить отправителя? Измените поле From в открытом письме и нажмите Refresh.

Create

Папка, в которой Mass Mailer создаёт подготовленные сообщения. По умолчанию выбирается Drafts, связанная с контекстом исходного письма, с fallback на стандартные Drafts Outlook.

Кнопка Change открывает Outlook Folder Picker.

Send

Папка, которую сканирует Send Prepared Drafts. Макрос ищет только собственные помеченные Mass Mailer сообщения в этой папке.

Это позволяет использовать отдельную очередь и не сканировать всю обычную папку Drafts.

Same as create

Устанавливает одну и ту же папку для создания и последующей отправки. Для больших рассылок это рекомендуемый сценарий.

Например, можно создать отдельную почтовую папку Mass Mailer Queue.

Выбор папок действует в текущей сессии Mass Mailer. При закрытии формы контекст сессии очищается; при следующем запуске маршрутизация определяется заново.
ПОЛУЧАТЕЛИ

Форматы адресов, импорт и проверка

Можно вставлять

sales@example.com John Smith <john@example.com> mailto:office@example.com one@example.com; two@example.com one@example.com, two@example.com

Разделителями могут быть новая строка, точка с запятой, запятая или табуляция.

Счётчик

Validуникальные адреса, которые войдут в рассылку
Invalidзначения, не прошедшие проверку формата
Duplicatesповторные адреса, автоматически исключённые

Import TXT / CSV

Кнопка Import позволяет выбрать файл .txt или .csv. Текст добавляется к уже существующему списку. В первую очередь используется UTF‑8; предусмотрен fallback для обычного текстового чтения.

Если присутствуют Invalid, перед стартом Mass Mailer покажет список первых проблемных значений и попросит подтверждение. Невалидные адреса не отправляются.

РЕЖИМЫ

Create drafts или Send now

Рекомендуется для проверки

Create drafts

Mass Mailer создаёт индивидуальные письма в папке Create, но не отправляет их.

  • Можно визуально проверить несколько писем.
  • Удобно для больших пакетов.
  • После проверки используется Send Prepared Drafts.
Прямая отправка

Send now

Каждое письмо после подготовки передаётся Outlook на отправку.

  • Есть отдельное подтверждение перед стартом.
  • Для больших пакетов показывается дополнительное предупреждение.
  • Серверные лимиты Outlook/Exchange не обходятся.
SEND PREPARED DRAFTS

Как безопасно отправляются подготовленные письма

При генерации Mass Mailer добавляет к своим письмам специальное пользовательское MAPI-свойство MassMailerGenerated. Кнопка Send Prepared Drafts работает только с такими письмами в выбранной папке Send.

1Выбранная папка SendСканируется только она
→
2MassMailerGeneratedОтбираются только помеченные письма
→
3ПроверкаНе отправлено, есть получатели, не inline response
→
4SendПередача письма Outlook
Обычные черновики Outlook без метки Mass Mailer не должны попадать в эту массовую отправку.
ПРОИЗВОДИТЕЛЬНОСТЬ

Что происходит при большой рассылке

Оптимизированный пакет

Движок загружает OFT-шаблон один раз, сохраняет базовое письмо и для последующих адресатов использует MailItem.Copy. Это уменьшает количество тяжёлых COM/MAPI операций.

Прогресс UI обновляется периодически, а не после каждой отдельной операции.

Что всё равно ограничивает скорость

  • Exchange / SMTP throttling.
  • Сетевые задержки.
  • Антиспам-политики сервера.
  • Размер и количество вложений.
  • Производительность локального Outlook-профиля.

Если быстрый batch-copy не удаётся безопасно использовать, в коде предусмотрен более консервативный per-item fallback.

TROUBLESHOOTING

Если что-то не работает

Subject: unavailable / Template snapshot is unavailable

Текущий snapshot шаблона недоступен. Закройте Mass Mailer, откройте или выберите корректный неотправленный email и запустите MassMail_Open снова.

Макрос пишет “Open a new email or select an unsent draft first”

Mass Mailer не нашёл подходящее письмо. Откройте новое письмо в отдельном окне либо выделите ровно один неотправленный черновик в Outlook.

В поле From отображается не тот аккаунт

Откройте рабочую копию через Edit, выберите нужное поле From в самом Outlook и нажмите Refresh. Mass Mailer берёт отправителя из письма-шаблона, а не из отдельного списка.

Send Prepared Drafts показывает (0)

Проверьте выбранную папку Send. В ней должны находиться неотправленные письма, созданные Mass Mailer и содержащие его MAPI-метку. При необходимости нажмите Same as create.

Outlook сообщает об inline response / письмо открыто в Reading Pane

Outlook не позволяет VBA отправить активный inline response. Переключитесь на другое письмо или закройте редактирование в Reading Pane и повторите Send Prepared Drafts.

После вставки адресов есть Invalid

Проверьте лишние комментарии, пробелы внутри адреса, отсутствие доменной части или другие символы. Форматы Name <email@example.com> и mailto:email@example.com поддерживаются.

Debug → Compile выдаёт Ambiguous name detected

Вероятнее всего в VBAProject одновременно находятся старый и новый модули с одинаковыми процедурами. Оставьте одну актуальную версию Mass Mailer.

Макрос не запускается вообще

Проверьте, что используется Outlook Classic, VBA разрешён политиками безопасности и проект компилируется без ошибок. В корпоративной среде ограничения могут задаваться администратором.

FAQ

Частые вопросы

Получатели видят друг друга?

Нет, если вы используете список Recipients по назначению: Mass Mailer создаёт отдельное письмо для каждого TO. Однако CC/BCC из шаблона сохраняются и будут одинаковыми во всех письмах.

Можно ли использовать одну папку и для создания, и для отправки?

Да. Для этого есть Same as create. Это особенно удобно с отдельной папкой Mass Mailer Queue.

Можно ли менять шаблон после запуска формы?

Да. Нажмите Edit, измените письмо в Outlook и затем Refresh. Без Refresh изменения не гарантированно попадут в snapshot.

Можно ли закрыть Mass Mailer во время обработки?

Нет. Пока идёт пакетная операция, форма блокирует закрытие, чтобы не оборвать сессию.

Mass Mailer обходит лимиты Exchange?

Нет. Макрос ускоряет локальную генерацию сообщений, но серверные ограничения, throttling и антиспам-политики остаются в силе.

QUICK START

Send a mailing in 7 steps

If Mass Mailer is already installed, this is the standard operating workflow.

  1. 1

    Create the source email

    In Outlook Classic, create a new message or open an unsent draft. Set the subject, body, signature, CC/BCC and the required From account.

  2. 2

    Run MassMail_Open

    The macro uses the active Inspector email first; if none is active, it tries to use one selected Outlook item.

  3. 3

  4. 4

    Add recipients

    If you created drafts, verify and send them

    Open a few generated messages, check From/TO/CC/BCC/attachments, then use Send Prepared Drafts.

The VBA editor must be available through Alt + F11. Corporate IT policies may restrict access.

TEMPLATE

How the source email is captured

Source priority

  1. The email in the active Outlook Inspector window.
  2. If there is no active Inspector: exactly one selected Outlook item.

The message must be unsent. A sent message cannot be used as the active template.

Template content

  • Subject and body.
  • Outlook formatting/signature stored in the OFT.
  • CC and BCC.
  • Attachments.
  • Sender / From context.
Core rule: source-email TO addresses are not used as the mailing list. For each generated message, TO is replaced with exactly one recipient from the Recipients box. Template CC and BCC are preserved.

Email Template buttons

Edit

Opens a working copy of the template in Outlook. After changing subject, body, From, etc., press Refresh.

Attach

Adds selected files directly to the stored template snapshot.

Refresh

Captures the currently open email again, including the template snapshot and sender context.

FROM & ROUTING

Sender and folders

From

The sender is not manually selected in Mass Mailer. It is inherited from the source/template email.

If the UI shows (Outlook default account), Outlook did not expose a separate SendUsingAccount value and will use the profile/default sending context.

To change the sender, change From in the Outlook template and press Refresh.

The folder where generated messages are created. The initial route normally follows the source-email account's Drafts folder, with a fallback to Outlook's default Drafts.

Change opens Outlook's Folder Picker.

Send

The folder scanned by Send Prepared Drafts. Only Mass Mailer-tagged messages in this selected folder are considered.

Same as create

Uses the same folder for creation and later prepared-draft sending. A dedicated Mass Mailer Queue folder is a clean setup for large mailings.

Folder choices are session context. Closing the form clears the session and routing is established again the next time Mass Mailer starts.

PERFORMANCE

Large-batch behavior

Optimized batch engine

The engine loads the OFT once, saves one base message and uses MailItem.Copy for subsequent recipients, reducing expensive COM/MAPI work.

UI progress updates are throttled rather than executed after every single operation.

Remaining bottlenecks

  • Exchange / SMTP throttling.
  • Network latency.
  • Server anti-spam policy.
  • Attachment size and count.
  • Local Outlook profile performance.

A conservative per-item fallback exists if the fast batch-copy route cannot be used safely.

TROUBLESHOOTING

Common problems

Subject: unavailable / Template snapshot is unavailable

The current template snapshot is unavailable. Close Mass Mailer, open or select a valid unsent email and run MassMail_Open again.

“Open a new email or select an unsent draft first”

Mass Mailer did not find a usable source. Open a new message in its own window or select exactly one unsent draft in Outlook.

The From identity is wrong

Use Edit, select the correct From account in Outlook, then press Refresh. Mass Mailer inherits sender context from the template rather than from a separate account selector.

Send Prepared Drafts shows (0)

Check the selected Send folder. It must contain unsent messages generated and tagged by Mass Mailer. Use Same as create if appropriate.

Outlook reports an inline response / Reading Pane issue

Outlook cannot VBA-send the current active inline response. Select another item or close the inline editor, then retry Send Prepared Drafts.

Recipient list contains Invalid values

Check comments, embedded spaces, missing domain portions or other invalid characters. Name <email@example.com> and mailto:email@example.com are supported.

Debug → Compile reports “Ambiguous name detected”

You likely have old and new engine modules containing identical public procedure names. Keep one current Mass Mailer engine version.

The macro does not run at all

Confirm you are using Outlook Classic, VBA is permitted by security policy, and the project compiles without errors. Corporate policy may require administrator assistance.

FAQ

Frequently asked questions

Can recipients see each other?

Not through the main recipient list: Mass Mailer creates one separate TO message per recipient. However, template CC/BCC values are preserved and therefore remain the same across the generated messages.

Can I use the same folder for creation and sending?

Yes. Use Same as create. A dedicated Mass Mailer Queue folder is a clean option.

Can I edit the template after opening Mass Mailer?

Yes. Use Edit, modify the Outlook message, then press Refresh so the snapshot is updated.

Can I close Mass Mailer during processing?

No. The form prevents closing while the batch operation is active.

Does Mass Mailer bypass Exchange limits?

No. It optimizes local message generation, but server quotas, throttling and anti-spam policies still apply.
