Mass Mailer 2.4 — website package
=================================

Ready for static hosting at:
https://znetw.ru/massmailerinfo

Files:
- index.html
- styles.css
- script.js
- assets/massmailer-interface.png

Features:
- complete Russian and English guide;
- RU/EN switch with language saved in localStorage;
- responsive desktop/mobile layout;
- printable selected-language version;
- clickable interface screenshot with full-size dialog;
- copy buttons for installation names/paths;
- no external libraries, fonts or CDN dependencies.

Deployment:
Upload the contents of this folder to the web root that serves
/znetw.ru/massmailerinfo (or to the corresponding directory configured
by your web server). Keep the relative assets/ directory structure intact.

The page is fully static and requires no backend.
