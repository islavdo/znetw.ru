Руководство пользователя MarkItDown

Локальное преобразование документов, таблиц, презентаций, PDF и других файлов в Markdown.

Версия для Windows · Qt-интерфейс

1. Для чего нужна программа

MarkItDown извлекает текст и структуру из разных типов файлов и сохраняет результат в формате .md. Markdown удобно использовать для поиска, баз знаний, документации, систем искусственного интеллекта и дальнейшей обработки текста.

Что умеет

  • Обрабатывать один файл или целую папку
  • Принимать файлы перетаскиванием
  • Показывать Markdown до открытия
  • Объединять результаты в один документ

Где находятся данные

  • Обработка выполняется локально
  • Результаты сохраняются на компьютере
  • Папку назначения выбирает пользователь
  • Исходные файлы не изменяются

2. Перед первым запуском

Что потребуется

  • 64-разрядная Windows 10 или 11.
  • Права на чтение исходных файлов и запись в папку результата.
  • Подключение к интернету только для первоначальной подготовки окружения.
  • Несколько гигабайт свободного места для программы, зависимостей и результатов.
Распакуйте или скопируйте всю папку программы. Не запускайте приложение прямо из ZIP-архива.
Не удаляйте служебные папки. Каталоги .python-runtime и .venv-gui содержат локальную среду выполнения.
Для переноса скопируйте папку целиком. На другом компьютере запустите Запустить GUI.bat; системный Python устанавливать не требуется.
Повторная установка. Если подготовка была прервана, снова запустите Запустить GUI.bat. Скрипт проверит окружение и продолжит настройку.

3. Запуск программы

Обычный запуск

Найдите ярлык MarkItDown на рабочем столе Windows.
Дважды щёлкните ярлык. Сначала появится небольшое окно загрузки, затем основной интерфейс.
После появления главного окна можно сразу добавлять документы.

Альтернативный способ — запустить файл Запустить GUI.bat из папки программы. Повседневный запуск выполняется без консольного окна.

Первый запуск. Если локальное окружение ещё не подготовлено, программа автоматически откроет установщик. Потребуется подключение к интернету и несколько минут. Последующие запуски будут быстрыми.
Важно: не перемещайте и не переименовывайте папку программы после создания ярлыка. Если папка была перемещена, создайте ярлык заново.

5. Быстрая конвертация

Добавьте файлы. Перетащите их из Проводника в большую область вверху либо нажмите «Добавить файлы».
Проверьте очередь. Ненужные строки можно выделить и удалить. Кнопки ↑ и ↓ меняют порядок.
Выберите папку результата. Если поле оставить пустым, каждый Markdown сохранится рядом со своим исходником.
Нажмите «Конвертировать». Первый запуск обработки может включать короткую фоновую подготовку движка.
Откройте результат. Выберите готовую строку и используйте кликабельный путь, «Открыть файл» или «Показать в папке».
Остановка выполняется безопасно: кнопка «Отмена» завершает текущий файл и не начинает следующий. Уже записанные результаты сохраняются.

6. Работа с папками

Папку можно перетащить в окно или выбрать кнопкой «Добавить папку». Программа просматривает вложенные каталоги и добавляет найденные файлы в очередь.

Сохранение структуры каталогов

Если выбрана общая папка результата, структура перетащенной папки сохраняется. Например:

Исходник: D:\Документы\Проект\Отчёты\май.pdf
Результат: D:\Markdown\Отчёты\май.md

Если папка результата не задана, файлы .md создаются рядом с соответствующими исходниками.

7. Настройки

НастройкаКогда использовать
ПерезаписыватьРазрешает заменить существующий файл с тем же именем. Если флажок выключен, программа покажет ошибку и сохранит старый результат.
ПлагиныВключает установленные расширения MarkItDown. Для обычных документов чаще всего не требуется.
Data URIСохраняет встроенные данные изображений в Markdown. Результат может стать значительно больше.
Объединить в один файлДополнительно создаёт общий Markdown из всех успешно обработанных документов.
ЗаголовкиДобавляет перед каждым разделом общего файла заголовок с именем исходного документа.

Имя объединённого документа должно заканчиваться на .md. Порядок разделов соответствует порядку файлов в очереди.

8. Просмотр и открытие результатов

  • Один щелчок по строке показывает исходный и ожидаемый выходной путь.
  • После успешной обработки в правой панели появляется Markdown.
  • Нажатие на путь исходника открывает исходный документ.
  • Нажатие на путь результата или кнопку «Открыть файл» открывает Markdown в назначенной Windows программе.
  • Кнопка «Показать в папке» открывает Проводник и выделяет готовый файл.
  • Двойной щелчок по строке очереди открывает исходник.

Состояния очереди: Ожидает, Обработка…, Готово и Ошибка. Текст ошибки доступен во всплывающей подсказке состояния.

9. Веб-интерфейс и Windows Server

Веб-режим удобен, когда конвертер работает на одном компьютере, а документы загружают из браузеров в локальной сети.

На сервере запустите Start Web GUI.bat.
На этом же компьютере откройте http://localhost:8080. С другого устройства используйте http://IP-СЕРВЕРА:8080.
Перетащите файлы в браузер, настройте порядок и параметры, затем нажмите «Конвертировать».
Просмотрите отдельные результаты, скачайте нужный .md или общий ZIP-архив.

Настройка сервера

Откройте web_settings.cmd в Блокноте, измените значения и перезапустите сервер.

ПараметрНазначениеПо умолчанию
MARKITDOWN_PORTTCP-порт веб-сервера8080
MARKITDOWN_HOSTСетевой интерфейс; 0.0.0.0 разрешает подключения из локальной сети0.0.0.0
MARKITDOWN_MAX_UPLOAD_MBОбщий предел одной загрузки500 МБ
MARKITDOWN_USER, MARKITDOWN_PASSWORDИмя и пароль Basic Auth; защита включается, когда заданы оба значенияне заданы
MARKITDOWN_NO_BROWSERЗначение 1 отключает автоматическое открытие браузера0
Не публикуйте встроенный сервер напрямую в интернете. Для внешнего доступа задайте пароль, ограничьте доступ брандмауэром и используйте HTTPS reverse proxy (например, IIS, Caddy или nginx).

Временные данные сохраняются в .web-data и автоматически удаляются примерно через 24 часа. Не используйте эту папку как постоянное хранилище.

ДокументыPDF, DOCX, TXT, Markdown, EPUB
ТаблицыXLSX, XLS, CSV
ПрезентацииPPTX
Веб и данныеHTML, HTM, XML, JSON, Jupyter Notebook

Качество результата зависит от содержимого. Сканированный PDF без текстового слоя требует OCR-расширения. Распознавание изображений и аудио может требовать дополнительных компонентов или настроек.

11. Если что-то не работает

Файл уже существует

Выберите другую папку, удалите старый результат либо включите «Перезаписывать».

Нет доступа к папке

Выберите папку внутри профиля пользователя, например «Документы». Проверьте, не открыт ли результат другой программой с блокировкой записи.

Файл не добавляется

Убедитесь, что это обычный локальный файл, он существует и доступен для чтения. Сетевой или облачный файл сначала лучше полностью скачать.

Ошибка обработки PDF или Office

Попробуйте открыть исходник в его штатной программе. Повреждённый или защищённый паролем документ может не конвертироваться.

Ярлык перестал работать

Проверьте, не была ли перемещена папка программы. Запустите Запустить GUI.bat непосредственно из неё или создайте новый ярлык.

Окно долго появляется

При первом запуске Windows может проверять новые библиотеки. Последующие запуски обычно быстрее. Не удаляйте папку .venv-gui.

Веб-страница не открывается с другого компьютера

Сначала проверьте адрес на сервере через localhost:8080. Затем узнайте IP-адрес сервера, разрешите выбранный порт в брандмауэре Windows и убедитесь, что устройства находятся в одной сети.

Получился пустой или неполный Markdown

Проверьте, выделяется ли текст в исходном документе. Для сканов нужен OCR. Сложная верстка, рукописный текст, защищённые файлы и повреждённые архивы могут извлекаться не полностью.

12. Советы для быстрой работы

  • Для больших заданий выбирайте отдельную локальную папку результата.
  • Не включайте Data URI без необходимости.
  • Сначала копируйте файлы с медленного сетевого диска на компьютер.
  • Обрабатывайте очень большие PDF отдельно от маленьких документов.
  • Не запускайте повторно уже готовую очередь без включённой перезаписи.
  • Во время обработки не перемещайте исходники и папку назначения.

13. Конфиденциальность и безопасность

Обычная конвертация выполняется локально на компьютере. Программа читает выбранные пользователем исходники и записывает Markdown в указанную папку.

  • Не открывайте неизвестные результаты без проверки исходных файлов.
  • Храните конфиденциальные документы в папках с подходящими правами доступа.
  • При включении сторонних плагинов учитывайте их собственные правила работы.
  • Не удаляйте исходники до проверки результата.

14. Частые вопросы

Исходные документы изменяются?

Нет. Программа читает исходники и создаёт отдельные файлы .md.

Куда сохраняется результат?

В выбранную папку результата. Если она не указана, отдельный Markdown сохраняется рядом с исходником.

Можно ли остановить очередь?

Да. «Отмена» завершает текущий файл и не начинает следующий; уже записанные результаты сохраняются.

Почему общий файл не заменяет отдельные?

Объединение создаёт дополнительный документ. Отдельные результаты сохраняются для проверки и повторного использования.

Нужен ли интернет во время конвертации?

Для обычной локальной конвертации — нет. Он может понадобиться при первой установке, а также плагинам или облачным функциям, если они включены.
